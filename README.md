# 📐 Cálculo de Reticulado

Una aplicación web interactiva para el análisis estructural de reticulados (cerchas y armaduras).

## 🌐 Demo en Vivo

Visita la aplicación: [https://TU-USUARIO.github.io/Calculo-de-reticulado/](https://TU-USUARIO.github.io/Calculo-de-reticulado/)

## ✨ Características

- 🔧 **Análisis Estructural Completo**: Calcula fuerzas internas, desplazamientos y reacciones
- 📊 **Visualización Interactiva**: Canvas HTML5 para visualizar la estructura en tiempo real
- ⚡ **Rápido y Eficiente**: Sin necesidad de instalación, funciona directamente en el navegador
- 🎨 **Interfaz Moderna**: Diseño limpio y responsivo
- 📱 **Compatible con Móviles**: Funciona en cualquier dispositivo

## 🚀 Funcionalidades

- ✅ Cálculo de reacciones en los apoyos
- ✅ Determinación de fuerzas axiales en barras (tracción/compresión)
- ✅ Cálculo de desplazamientos nodales
- ✅ Visualización gráfica de la estructura
- ✅ Configuración personalizable de nodos y elementos
- ✅ Soporte para diferentes tipos de apoyos

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura de la página
- **CSS3**: Estilos y animaciones
- **JavaScript**: Lógica de cálculo y visualización
- **Canvas API**: Renderizado de la estructura

## 📖 Cómo Usar

1. **Configurar la estructura**: 
   - Ingresa el número de nodos y elementos
   - Define el módulo de elasticidad y el área de sección
   
2. **Generar estructura**:
   - Haz clic en "Generar Estructura" para crear una configuración automática
   - O utiliza la estructura de ejemplo precargada

3. **Calcular**:
   - Haz clic en "Calcular" para obtener los resultados del análisis
   - Revisa las fuerzas en los elementos y los desplazamientos

## 🎓 Conceptos de Ingeniería

Esta aplicación implementa conceptos fundamentales de análisis estructural:

- **Método de Rigidez Directa**: Para el análisis de estructuras
- **Ecuaciones de Equilibrio**: Para calcular reacciones
- **Ley de Hooke**: Para relaciones esfuerzo-deformación
- **Análisis de Fuerzas Internas**: Tracción y compresión en elementos
